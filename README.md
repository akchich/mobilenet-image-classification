\# MobileNet Image Classification App



Application web développée avec Flask permettant d'importer une image, de l'analyser avec un modèle MobileNetV2 pré-entraîné sur ImageNet, puis d'enregistrer le résultat de l'analyse dans MongoDB.



\## Apprentissages autour du projet



Ce projet m'a permis d'approfondir le fonctionnement des réseaux de neurones convolutifs (CNN), notamment :



\- convolution et extraction de caractéristiques ;

\- fonctions d’activation comme ReLU ;

\- pooling et réduction de dimension ;

\- classification avec Softmax ;

\- différence entre entraînement et inférence ;

\- utilisation d’un modèle pré-entraîné.



\## Fonctionnalités



\- Import d'une image

\- Prétraitement avec TensorFlow/Keras

\- Classification avec MobileNetV2

\- Affichage du taux de confiance

\- Stockage des résultats dans MongoDB
